> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Land the five design-bearing kit variants from the backlog — validated chart palette (+ wiring), modal sizes, flat nav, richer shell brand, product-appbar example — non-breaking, folding onto the held Precision + Batch A commits toward `v1.1.0`.

**Architecture:** Token-driven CSS kit; `tokens/build.mjs` is value-driven (generic flatten) so a new `chart` token group cascades with no build change; `dist/` is committed & regenerated. Spec: `docs/superpowers/specs/2026-07-23-freeday-v1.1-batch-b-design.md`.

**Tech Stack:** Pure CSS + DTCG `tokens.json` + zero-dep JS enhancers; Node build; `node --test`. No new deps.

## Global Constraints

- Component CSS/JS: Tier-2/3 tokens only, zero raw hex/color (geometry px OK). The **only** place chart hex lives is the `chart` token group in `tokens.json`; components reference `var(--chart-N)`.
- **WCAG AA for UI text/controls** maintained; `test/contrast.test.mjs` stays green (`# pass 9`, `# fail 0`). **Do NOT add `--chart-*` pairings to `contrast.test.mjs`** — chart-palette a11y is governed by the dataviz categorical validator (recorded in the spec), gridlines are intentionally recessive, and light series slots use the relief rule (legend + labels).
- Chart palette **validation record** (from the dataviz validator, Freeday surfaces): light `#ffffff` — band/chroma/CVD(9.1≥8)/normal-vision(19.6≥15) PASS, contrast WARN on slots 3/4/5 → relief rule; dark `#0e111a` — all PASS. If any chart hex changes, rerun `node scripts/validate_palette.js` and update the record.
- **No API/class/token renames** — everything additive ⇒ non-breaking. `fdy-` prefix, `window.Freeday*` stable.
- `dist/` committed & deterministic (`node tokens/build.mjs`, rebuild = no diff). Work from repo root.
