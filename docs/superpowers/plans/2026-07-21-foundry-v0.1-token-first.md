# Foundry v0.1 (Token-First) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bangun pipeline design-system `tokens.json → CSS variables → komponen → docs` end-to-end, dengan 4 komponen inti (button, input, card, badge) untuk membuktikan arsitektur token 3-lapis Foundry berjalan utuh.

**Architecture:** `tokens/tokens.json` (DTCG-lite) adalah sumber sejati. Script Node murni `tokens/build.mjs` mem-flatten & me-resolve alias token jadi `dist/foundry.tokens.css` (3-lapis: primitive → semantic → component, dengan light/dark/density), lalu meng-concat `src/base.css` + `src/components/*.css` jadi `dist/foundry.css`. `docs/index.html` mengimpor kedua file dist sebagai referensi hidup dengan toggle theme & density.

**Tech Stack:** Node ≥ 20 (built-in `node:test`, `node:fs`, ESM) · CSS murni · zero runtime dependency.

## Global Constraints

- **Node ≥ 20** — memakai `node --test` (built-in runner) dan ESM (`"type":"module"`).
- **Zero dependency** — tidak ada paket npm eksternal di v0.1 (YAGNI). Hanya Node stdlib.
- **Prefix kelas komponen:** `fdy-` (BEM ringkas: `fdy-btn`, `fdy-card__title`, `fdy-btn--danger`).
- **Token discipline (pragmatis):** Warna **selalu** token (tidak pernah hex mentah di komponen). Spasi yang cocok skala `--space-*` **wajib** pakai token (mis. `.5rem` → `var(--space-2)`). Literal lokal-komponen tanpa padanan token (padding relatif `em`, hairline `1.5px`, spread focus `3px`, `min-height` ad-hoc) **boleh** sebagai literal — lihat spec §9.
- **Nilai token = sumber kebenaran di spec** `docs/superpowers/specs/2026-07-21-foundry-ui-kit-design.md` §5. Setiap nilai warna/skala di plan ini disalin verbatim dari sana.
- **Aksesibilitas:** kontras WCAG AA; `:focus-visible` selalu terlihat (outline 2px `var(--focus-ring)`); hormati `prefers-reduced-motion`. **ARIA:** HTML native dulu ("no ARIA is better than bad ARIA"); komponen ikut kontrak spec §11.3; markup di docs = versi aksesibel (bukan hanya visual).
- **`dist/` di-commit** (lihat `.gitignore`) agar project lain bisa impor tanpa build.
- **Path root:** semua path relatif terhadap root repo (folder "UI KIT"). Struktur `foundry/` di spec = root repo ini.
- **Format commit:** Conventional Commits (`feat:`, `chore:`, `docs:`, `test:`).

## File Structure

| File | Tanggung jawab |
|---|---|
| `package.json` | Metadata, `type:module`, script `build` & `test`. |
| `tokens/tokens.json` | Sumber sejati token (DTCG-lite): primitive ramps + scales + semantic (light + `$dark`) + density. |
| `tokens/build.mjs` | Pure functions `buildTokensCss` & `bundleCss` + CLI `main()` yang menulis `dist/`. |
| `test/build.test.mjs` | Unit test untuk transformasi murni di `build.mjs`. |
| `src/base.css` | Reset ringan + default elemen via token + `:focus-visible` + reduced-motion. |
| `src/components/button.css` | `.fdy-btn` + varian/ukuran/state. |
| `src/components/input.css` | `.fdy-field`, `.fdy-input`, `.fdy-label`, `.fdy-help`. |
| `src/components/card.css` | `.fdy-card` + sub-elemen. |
| `src/components/badge.css` | `.fdy-badge` + varian status. |
| `dist/foundry.tokens.css` | **Generated.** CSS variables (light/dark/density). |
| `dist/foundry.css` | **Generated.** Bundel `base.css` + semua `components/*.css`. |
| `docs/index.html` | Referensi hidup: import dist, toggle theme+density, showcase token & komponen. |
| `README.md` | Cara build, struktur, cara konsumsi. |

- [ ] **Step 3: Implementasi `tokens/build.mjs`**

```js
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

// {a.b.c} -> var(--a-b-c) ; literal lain apa adanya
export function resolveValue(raw) {
  const m = /^\{([^}]+)\}$/.exec(String(raw).trim());
  return m ? `var(--${m[1].replace(/\./g, '-')})` : String(raw);
}

// leaf = objek dengan $value ; name = path digabung '-'
export function flatten(tokens, prefix = []) {
  const out = [];
  for (const [key, val] of Object.entries(tokens)) {
    if (val && typeof val === 'object' && '$value' in val) {
      out.push({
        name: [...prefix, key].join('-'),
        value: val.$value,
        dark: val.$dark,
        compact: val.$compact,
      });
    } else if (val && typeof val === 'object') {
      out.push(...flatten(val, [...prefix, key]));
    }
  }
  return out;
}

const decl = (name, raw) => `  --${name}: ${resolveValue(raw)};`;

export function buildTokensCss(tokens) {
  const flat = flatten(tokens);
  const root = flat.map(t => decl(t.name, t.value)).join('\n');
  const darkTokens = flat.filter(t => t.dark !== undefined);
  const dark = darkTokens.map(t => decl(t.name, t.dark)).join('\n');
  const lightReassert = darkTokens.map(t => decl(t.name, t.value)).join('\n');
  const compactTokens = flat.filter(t => t.compact !== undefined);
  const compact = compactTokens.map(t => decl(t.name, t.compact)).join('\n');

  return `/* Foundry tokens — GENERATED by tokens/build.mjs. Do not edit by hand. */
:root {
${root}
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
${dark}
  }
}
:root[data-theme="dark"] {
${dark}
}
:root[data-theme="light"] {
${lightReassert}
}
:root[data-density="compact"] {
${compact}
}
`;
}

export function main() {
  const here = dirname(fileURLToPath(import.meta.url));
  const root = join(here, '..');
  const tokens = JSON.parse(readFileSync(join(root, 'tokens/tokens.json'), 'utf8'));
  const css = buildTokensCss(tokens);
  mkdirSync(join(root, 'dist'), { recursive: true });
  writeFileSync(join(root, 'dist/foundry.tokens.css'), css);
  console.log('Wrote dist/foundry.tokens.css');
}

if (import.meta.url === `file://${process.argv[1]}`) main();
```
