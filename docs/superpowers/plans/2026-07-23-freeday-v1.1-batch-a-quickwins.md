## Global Constraints

- Component CSS touches **Tier-2/3 tokens only** — zero raw hex/color. (Box-shadow/border/outline **geometry** px — offsets, widths, radii, spreads — are acceptable and pre-existing; only raw COLOR or off-scale layout spacing is a violation.)
- **WCAG AA** maintained light + dark; `test/contrast.test.mjs` must stay green (`# pass 9`, `# fail 0`). New tokens added here are decorative/dimensional and are not contrast-graph pairings.
- **No API/class/token renames.** New tokens/exports are additive. `fdy-` prefix, `window.Freeday*`, existing `--*` names all stable ⇒ non-breaking.
- **Zero visual change** is the bar for the `selection.css` tokenization (Task 1): each new token's value must equal the literal it replaces (no dark overrides), so rendering is identical.
- `dist/` committed & deterministic (rebuild = no diff). Rebuild with `node tokens/build.mjs`.
- Work from repo root.

### Task 1: #6 — Tokenize `selection.css` (faithful, zero visual change)

**Files:**
- Modify: `tokens/tokens.json` (`control` group + two `color` tokens)
- Modify: `src/components/selection.css`

**Interfaces:**
- Produces new tokens: `--control-box`, `--control-switch-w`, `--control-switch-h`, `--color-switch-thumb`, `--color-shadow-inset`.

- [ ] **Step 1: Add the tokens (values equal to the literals they replace).**

In `tokens/tokens.json`, extend the `control` group and add two color tokens:
```json
"control": { "h": { "$value": "2.5rem", "$compact": "2rem" }, "box": { "$value": "1.15rem" }, "switch-w": { "$value": "2.4rem" }, "switch-h": { "$value": "1.35rem" } },
```
and inside the `color` object add:
```json
"switch-thumb": { "$value": "{slate.0}" },
"shadow-inset": { "$value": "rgba(16,14,30,.06)" },
```
(`{slate.0}` = `#ffffff`, matching the current `#fff`; `--color-shadow-inset` holds the current inset color verbatim. No `$dark` overrides — behavior stays identical in both themes.)

- [ ] **Step 2: Replace the literals in `src/components/selection.css` with the tokens.**

Apply exactly these swaps (leave all glyph-draw geometry — `.62rem`/`.55rem`/`.6rem`, `top:2px`, `left:2px`, `- 4px`, `translateX`, `1rem 1rem` glyph shadows — as-is; only control DIMENSIONS and raw COLORS change):
- `width:1.15rem;height:1.15rem` → `width:var(--control-box);height:var(--control-box)` (lines 3 and 19)
- `box-shadow:inset 0 1px 2px rgba(16,14,30,.06)` → `box-shadow:inset 0 1px 2px var(--color-shadow-inset)` (lines 3 and 19)
- switch input `width:2.4rem;height:1.35rem` → `width:var(--control-switch-w);height:var(--control-switch-h)` (line 13)
- switch thumb `width:calc(1.35rem - 4px);height:calc(1.35rem - 4px)` → `width:calc(var(--control-switch-h) - 4px);height:calc(var(--control-switch-h) - 4px)` (line 14)
- switch thumb `background:#fff` → `background:var(--color-switch-thumb)` (line 14)
- checked thumb `transform:translateX(1.05rem)` → `transform:translateX(calc(var(--control-switch-w) - var(--control-switch-h)))` (line 16) — `2.4 − 1.35 = 1.05rem`, identical.

- [ ] **Step 3: Rebuild.** Run: `node tokens/build.mjs`. Confirm `--control-switch-w: 2.4rem;` and `--color-switch-thumb: var(--slate-0);` appear in `dist/freeday.tokens.css`, and the tokenized rules in `dist/freeday.css`.

- [ ] **Step 4: Test.** Run: `npm test`. Expected `# pass 9`, `# fail 0` (values unchanged ⇒ no contrast change).

- [ ] **Step 5: Verify zero visual drift statically.** Grep the built CSS to confirm the switch/checkbox rules now resolve to the same computed values (e.g. `--control-switch-w` = `2.4rem`, `--color-switch-thumb` → `#ffffff`). No browser needed — value-equality is the guarantee.

- [ ] **Step 6: Commit.**
```bash
git add tokens/tokens.json src/components/selection.css dist/
git commit -m "refactor(tokens): tokenize selection.css control dims + raw colors (no visual change)"
```
