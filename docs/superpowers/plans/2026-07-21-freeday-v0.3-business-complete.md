# Freeday v0.3 (Business-complete) — Implementation Plan

**Goal:** Naikkan Freeday ke tingkat "sistem desain produk nyata" (setara MudBlazor/PrimeVue): docs jadi demo-site berbasis app-shell (bukan halaman polos), table dapat toolbar/filter/sort/pagination/selection/states, plus komponen roundout (alert, toast, tooltip, tabs, breadcrumb, pagination, avatar, spinner, progress, skeleton).

**Architecture:** Tetap token-driven (Tier 1→2→3), CSS murni + enhancer JS opsional (pola sama seperti `freeday-select.js`). `tokens/build.mjs` sudah auto-bundle `src/components/*.css` + copy `src/*.js` → `dist/`. 0 dependency runtime. Native-first ARIA (WAI-ARIA APG).

**Tech Stack:** CSS + tokens.json (DTCG-lite) · Node ≥20 (`node --test`) · vanilla enhancer JS.

## Global Constraints
- ZERO runtime dependency; ESM build; Node ≥20; pure-function tests tetap hijau.
- Prefix kelas `fdy-`; BEM ringkas. Komponen sentuh **hanya** token Tier-2/3 (whitelist literal dekoratif spec §9).
- **WCAG AA** teks & kontrol ≥4.5:1 (non-text 1.4.11 ≥3:1) di light & dark, semua state — diverifikasi tiap komponen berwarna.
- Native-first ARIA (APG): tabs (role=tablist/tab/tabpanel, keyboard), toast (`role=status`/`aria-live`), tooltip (`role=tooltip`+`aria-describedby`), alert (`role=alert` untuk danger), pagination (`nav`+`aria-current`), breadcrumb (`nav`+`aria-current`), table selection (checkbox), sort (`aria-sort`).
- `prefers-reduced-motion` dihormati (toast/skeleton/spinner animasi di-gate atau tetap subtle).
- `dist/` di-commit. Conventional Commits. Branch tetap `feat/v0.2-rich-refinement` (user minta tak switch branch); commit prefix `feat(v0.3)`.

## Batches (tiap batch: build + `node --test` + AA verify + commit; JS/berisiko → review subagent)

### B1 — Tokens
- Tambah `--color-inverse-surface` (light {slate.900}, dark {slate.100}) + `--color-inverse-text` (light {slate.0}, dark {slate.900}) untuk tooltip & toast gelap. AA-verify.

### B2 — Feedback (CSS): alert, toast, tooltip
- `alert.css`: `.fdy-alert` + `--success/--warning/--danger/--info`, ikon slot, judul, teks, tombol close; danger/error pakai `role=alert` di markup.
- `toast.css`: `.fdy-toast` (+ varian), `.fdy-toast-region` (pojok, `aria-live`), animasi masuk/keluar gated reduced-motion.
- `tooltip.css`: `.fdy-tooltip` (inverse bg), tampil via `:hover`/`:focus-within` + `role=tooltip`/`aria-describedby`.

### B3 — Navigation (CSS): tabs, breadcrumb, pagination
- `tabs.css`: `.fdy-tabs/__list/__tab/__panel`, garis bawah aktif primary, `:focus-visible`.
- `breadcrumb.css`: `.fdy-breadcrumb` (`nav`>ol), separator, `aria-current="page"`.
- `pagination.css`: `.fdy-pagination` (nav>ul), tombol prev/next/number, `aria-current`, disabled.

### B4 — Data display (CSS): avatar, spinner, progress, skeleton
- `avatar.css`: inisial (primary-soft + primary-strong AA), ukuran sm/md/lg, `--group`.
- `spinner.css`: `.fdy-spinner` (border animasi), `prefers-reduced-motion` → tetap tapi lambat.
- `progress.css`: `.fdy-progress` (track surface-3 + bar primary), `role=progressbar` di markup, varian indeterminate.
- `skeleton.css`: `.fdy-skeleton` shimmer surface-2→3, gated reduced-motion.

### B5 — Table v2 (CSS + JS)
- `table.css` tambah: `.fdy-table-toolbar` (search + actions), `.fdy-table__select` (checkbox col), `tr[aria-selected]`, `.fdy-table__sort` (button di th), state rows.
- `states.css`: `.fdy-state` (empty/loading/error: ikon + judul + teks + aksi).
- `freeday-table.js`: enhancer opsional — client-side sort (`data-sort`), filter/search (`[data-fdy-table-search]`), pagination, "select all". `aria-sort` sync, emit `fdy-table-change`.

### B6 — JS enhancers: tabs, toast
- `freeday-tabs.js`: APG tabs (Arrow/Home/End, roving tabindex, `aria-selected`, panel show/hide).
- `freeday-toast.js`: `Freeday.toast({variant,title,message,timeout})` → buat node di region `aria-live`, auto-dismiss, tombol close.

### B7 — Docs demo-site (rebuild `docs/index.html`)
- Bungkus dengan `fdy-app` (sidebar nav persisten link ke section, topbar theme/density, hero ringkas). Tiap komponen di section ber-frame kartu, contoh hidup + status. Sertakan semua enhancer JS. Ganti nuansa "polos" → showcase rapi.

### B8 — Review + finalize
- Review subagent (opus) untuk table.js/tabs.js/toast.js + docs a11y. Fix. `node --test` 5/5, build deterministik. Tag `v0.3`. Tulis ringkasan `HANDOFF.md` untuk user cek besok.
